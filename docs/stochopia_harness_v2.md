# 股票合约设计 Harness v2（2026-10-10）

后续默认搜索目标已改为结构发现，见 [新 Harness 说明](stochopia_harness_discovery.md)。本页保留 v2 经济评价与历史收益搜索记录；复现其选优使用 `--research-goal return`。

本次修改解决首轮实验的三个辨识问题：有限 P 原子容易诱导支付集中，单点需求不能代表一个收益区间，历史最佳上涨不能单独证明反馈有效。输入仍是股票投资需求，输出仍是固定 DSL 合约，不引入客户画像、语言生长、训练模型或新的安全/hash 系统。

## 需求与分布

保留投入 100 万元、期限三个月、按 Q 模型公允现值成交，以及保本 0%／非保本 20% 的最终损失上限。原公开锚点保留，新增以下区间的有限网格检查：

| 需求 | 新增检查 |
|---|---|
| 回撤保护、参与上涨 | 股票到期比率 0.90–1.00 的净收益至少 0；1.10–1.20 至少 1% |
| 温和涨跌均有收益 | 到期比率 0.80–0.90 和 1.10–1.20 的净收益均至少 1% |

每段默认 11 个点，是研究夹具，不是所有实数终值的证明。金额等原参数已经确认；新增区间与分布参数是本次公开、可调整的合成研究假设，不冒称真实客户委托。

P 用三个连续 GBM 假设，每个默认 64 条三个月路径、权重 1/3：中心年化 drift 6%／vol 20%，偏涨 18%／24%，偏跌 -12%／28%。开发与留出使用独立随机种子，各候选共用相同对应批次。P 参数不改 Q 输入；这些分布未做市场校准。

同终值、不同历史的公共路径对照用于判断支付是否依赖路径；当前不把路径复杂度当需求，也不强制所有任务使用亚式或提前终止。

## 评分与反馈

默认继续此前确定的口径：所有需求约束达标后，最大化各 P 分布按公开概率加权的期望净收益。

`score_mode="worst_distribution"` 是显式可选口径：最大化三个 P 假设中最低的期望净收益。它改变偏好与排序，不能与默认均值结果混合。两种模式都报告分布均值、最差分布收益、期望利润和开发—留出差异。

创新不加入任意加分：数字抹除的 AST 形状、固定公共支付探针上的收益向量、相对种子的 RMS 差异、同终值路径待遇分别报告。探针相似不证明全域语义等价，探针不同也不证明市场新颖性。

约束失败仍为 `score=None`。反馈附违反的约束、正负 margin 和归一化违约程度；若没有可行解，选择违约最小候选继续提案，不能将它当作正式收益赢家。全部失败时完整记账，不运行留出。

v2 生成反馈只给开发汇总、约束和公共探针，不给逐条实际 P 路径/收益、episode 或留出种子。这是实验输入规则调整，不新增隔离设施。参数提示明确要求数值标量，说明文字放 rationale；旧工件不自动清理或修复。

## 搜索与对照

- `feedback`：下一轮接收之前的开发反馈与父代。同轮反馈冻结。
- `independent`：相同公开需求和条件，相同提案次数，但不携带父代或历史反馈；所有候选仍经过相同评价和择优。
- `parent_policy="alternating-diverse"`：在反馈搜索中交替使用最佳可行父代与公共支付行为较远的可行父代。多样性不改变收益评分，RMS 判等容差为 1e-9。

记录提案次数、API 调用及供应商实际 token。相同调用数不等于相同推理计算量。两轮搜索只有一次跨轮更新，离线夹具验收不能证明反馈改进或 RSI。

另提供标准产品族的有限参数网格：封顶看涨价差、单层/双层双向数字支付、含看跌腿的组合。默认四族各 6 个，共 24 次评价，使用同一目标和约束，单独保存并冻结后留出检查，不把基线优化结果注入独立采样。该网格含历史候选出现过的参数，属于事后结构对照；新模型实验前应冻结参数范围。它不是全局最优，预算也不是模型的四次 API 提案预算。

## 现金流与价格验收边界

每个候选的全部 P 路径使用 DSL 解释器批量执行现金流，再按实际购买预算算收益；每个分布一条代表路径执行完整询问、报价、提交、账户结算与独立 replay，并检查批量收益与账户收益一致。默认是 192 条评分路径和 3 条代表回放，不能称 192 条完整环境回放。

自动终止后收到的现金保持未投资现金。提前终止抑制到期腿的真实账户一致性已覆盖。所有场景共享发行时 Q 输入，合约按同一报价归一化名义本金。

Q 交易价沿用现有估值器及共同 seed。另用独立 Q seed 报告价格偏差与 MC 标准误，诊断不改主成交价或给奖励加权。**多个批次同时漏掉稀有支付时，价格差异和估计标准误可能都是零；该审计不证明定价准确。** 小路径数 smoke 只验流程。P 使用分层/反向配对抽样，因此不将逐路径 std/√N 冒称独立样本标准误；报告收益离散度和独立留出差异。

适配器已修正 `premium → 无条件到期 pay` 的支付下界；条件支付与提前终止仍用原保守规则。这是独立 DSL 研究适配修正，没有修改正式 benchmark v3。已保存 v1 工件与原始分数未改；旧 v1 需求和目标仍可调用，但用修正后的适配器重跑误拒候选，分数可能与原日志不同。

## 入口

股票专用 CLI 和 `task.json` 现在默认 v2；`run_search()` 函数保留 v1 默认以兼容原调用，CLI 可显式 `--demand-protocol v1`。旧 pipeline 自动使用 v1。四模型 API 比较入口支持同一 protocol/config/search-mode，模型与需求仍分组保存。

```sh
# OpenHyra 根目录；先运行离线流程，不读取 API key。
../Stochopia/.venv/bin/python experiments/run_stochopia_structuring.py --generator offline --demand two-way-risk20 --demand-protocol v2 --parent-policy alternating-diverse --output artifacts/v2-feedback
../Stochopia/.venv/bin/python experiments/run_stochopia_structuring.py --generator offline --demand two-way-risk20 --demand-protocol v2 --search-mode independent --output artifacts/v2-independent
../Stochopia/.venv/bin/python experiments/run_stochopia_standard_baselines.py --demand two-way-risk20 --output artifacts/v2-standard-controls
```

使用 `--eval-config 文件.json` 改参数，例如 `{"score_mode":"worst_distribution"}`。应为每个模式创建新输出目录。正式 API 对照需要另定预算与 Q 精度；本轮没有新付费调用，Step 保持暂停。

## 本轮实际验证

Haiku 和 DeepSeek 的 32 个历史候选分组离线转评，另含各任务种子；按 v2 连续 P 和区间需求重评，不调用模型，不回填旧成绩。这是冻结 v1 提案向新评价任务的转移，不是模型在新 Harness 下重新搜索。

同一个 DeepSeek 双层支付合约，原七路径均值 35.3422%，在本次连续 P 开发均值 7.5032%、留出 7.2338%；中心分布开发收益 -0.3446%。改用最差分布聚合时，本组已有候选会改选种子。这直接显示评分分布及偏好会影响结论，不证明哪种合成分布是真实市场。

24 次标准族控制在该任务找到同样的双层支付与相同分数；因网格包含历史参数，这只说明已有标准族能够表达它，不是独立预测胜负。

转评、标准控制与实际回放证据在 `artifacts/stochopia-harness-v2-20261010/transfer_audit.json`。可用保存的 `transfer_audit.py 新目录` 重跑；旧生成原始记录仍在 20261009 目录。

## 可选结构探索支线（2026-10-11）

`--proposal-strategy balanced-structure` 在完整提案序列中交替分配 `refine` 与 `structure-exploration`；探索焦点轮换路径统计、障碍/自动终止、路径准入与终值支付组合。要求说明机制为何满足需求和改善经济收益，允许明确报告没有优势。选优仍使用原约束与期望收益，不加创新奖励；默认 `default` 保留原提示行为。它是提示分工，不修改 DSL、模型权重或 Harness 本身，不能据此称 RSI。

20261011 四调用 pilot 用默认推理与显式输出额度 393216，Q 131072 路径、P 每分布 65536 路径、`score_mode="mean"`。两次连接中断，无自动重试；两次完整返回中一个通过约束。新赢家仍终值支付，开发 38.0478%、留出 37.6655%；旧赢家另按相同 P/Q 批次重购重评为 89.8286%、89.1702%。本次独立从手写种子启动，旧赢家未送入提示，因此不是上一批递归续跑或同条件提示消融。批次精度变化也不能称提示改进。原始文件与成交价保留，证据见 `artifacts/deepseek-structural-exploration-20261011/analysis.md`。

适配器的本金下界修正扩展至组合中的无条件到期支付；条件分支不自动保留该下界，有提前终止时仍保守处理。只改研究 DSL 适配，不改正式 benchmark v3。较大路径批次减少尾部噪声，但不能证明收敛、市场校准或产品新颖性。

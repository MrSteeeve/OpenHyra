# 路径需求与受控结构发现：评审修正版

协议 `stochopia-controlled-path-study.v2`，2026-10-12。当前交付是离线预检、可调用的配对研究入口、目录与盲审工件接口；没有新增付费调用，没有正式显著性或专家原创性结论。

## 研究目标与证据层

主要事件：固定任务／满足率目标下，模型候选的总服务资金成本比预算内优化目录更接近同一有限市场的理论成本下界，改进超过预先固定容差，且在 P=Q 条件下仍满足同一要求并优于该条件下重新优化的目录。它是优化发现证据，不是金融市场首创证据。

单独报告三维观察前沿外移：联合满足概率、总服务资金成本、回撤 CVaR。不得被任何有效目录点弱支配，并至少一维越过观察到的整个参考范围且超过固定容差。当前采用这个保守的充分条件，不声称穷尽所有前沿外移。固定目标的成本改进与三维改善分开。

是否匹配已知结构、同终值异历史差异、对冲暴露、程序复杂度，以及真实专家盲审，均作为辅助证据，不进入主要事件。未匹配、腿数组合拟合失败、计算预算耗尽都不能直接计作原创。

## P 与 Q 的关系

P/Q 使用相同 CRR 上下跳幅和同一 sigma 输入，基准 sigma=.20、r=.02、股息=0，P 只增加公布的风险溢价 Sharpe×sigma，初始合成 Sharpe=.30。风险中性上行概率 q=(exp((r-div)dt)-d)/(u-d)，P 上行概率 p=(exp((r-div+Sharpe*sigma)dt)-d)/(u-d)。dt=1/12。

离散二点分布的实际方差随概率略变，不能称两测度每一步的有限样本方差完全相等；它们对应相同扩散波动率参数与连续极限。没有沿用高波动 P/低波动 Q 三混合设置。另用 Sharpe=0 做 P=Q 完整预检，目录重新优化。同 P=Q 结果消除本轮特定测度设置的解释，不能证明与所有市场模型设定无关。

## 12 个月、按月观察的灵活需求

价格树重组，但完整市场历史节点保留：12个月4096条完整路径、8191个历史节点，以免均价、回撤、累计支付被股价节点错误合并。监控频率明确为月度，不保证月内最大回撤。

`PathDemand` 配置金额／期限、每月取款、财富目标、回撤门槛、最低联合满足概率、提前退出情景与折价、可否部分出售。合成初始例为100万元、12个月、第1/2月各1%，第4月2%、第6月3%、第9月2%的现金支出；累计调整财富目标1.02倍固定交付规模B，回撤15%，最低联合满足率95%。这些不是正式客户来源或已确认最终任务，预检失败不得事后自动调参制造成功。

默认不允许部分出售。全额提前退出按当月已支付现金之后的剩余Q价值×(1−退出折价)，初始合成折价1%，可配置；不免费添加面额保底赎回权。事件示例为持有至到期70%、第6月退出15%、第9月退出15%。默认独立于市场；可另注册按已观察股价的条件触发，该时点未发生的信息不得影响事件。条款不可引用客户外生事件。

每月顺序：合约当期支付到账；先用可用现金满足取款；仅在注册的部分出售对照中以出售补足缺口；再执行全额退出；最后计算除息后财富及回撤。同月全额退出款不用于较早发生的取款要求。退出后不再收未来票息，剩余现金仍可支付未来外部支出。

财富=可用现金+存续产品除息Q价值+已经支付给客户的外部取款。取款不制造虚假回撤，未满足的取款不虚增财富。最大回撤对此前财富高点计算，回撤CVaR采用离散事件概率的最差5%尾部。

部分出售为独立预注册对照，初始该对照按公允价、无部分出售折价；全额退出折价仍保持。对照按固定总投入B评价，只比较满足度／回撤，不作最低成本或整体可行性判定；其理论模块当前不支持，显式报 unsupported，不使用无部分出售的理论界给它发证。

## 购买成本、未用预算与模型边界

固定交付规模B，现金义务和到期目标按B定义，不把每份合约都缩放为投入B。Q估值确定合约购买价C；环境为同一候选计算达到规定满足率所需的最少操作现金储备R。主要成本为总服务资金K=C+R，必须不超过B；初始需求账户财富也是K。

未分配的B−K留在需求账户之外，不参与需求满足度、回撤或自由再投资。因此成本下降确实表示完成同一义务所需初始资金下降，没有把全部剩余预算免费算成产品保护。现金储备收益率固定为0，现金／债券及按交付日历支付控制均纳入目录。

默认无部分出售时，每个路径／退出案例需要的R由现金缺口、绝对到期目标缺口和各历史高点回撤约束取最大值，再按P权重取满足率分位数。理论模块同时优化C和R，目标也是K。部分出售时联合满足率不随R单调增加，因此对照固定投入B，不估计最少R或最低成本，理论界暂不支持。旧`fixed_budget_leg_control`只用于历史回归，不进入主结论。

研究现金流要求每个日期非负，单节点支付≤4B，初始融资由购买价单独记账。该上限定义了有限优化类；不是针对连续无界支付的全局结论。浮点需求比较使用B×1e−9元、回撤1e−9的数值容差，不是额外经济风险容忍；主要经济改进容差初始为500元。

## 理论最优前沿与 API 决策门

理论模块逐历史节点配置一个支付变量，不随外部事件复制支付决策。剩余价值按Q向后线性递推，构造逐案例现金可用性、累计调整财富、历史高点回撤及到期要求。硬要求使用LP；软联合满足率使用MILP，每个不可区分的市场历史／客户端事件案例一个成功变量；提前退出后经济结果相同的路径合并以减少计算量，最后在全部原始案例上重评，约束整组要求的联合满足。

货币变量按预算归一化后求解，输出还原为人民币并由同一环境独立重评。输出 solver status、可行上方成本、最小成本下界、gap、实际满足率、限制与支付表。只有求解器证明最优且环境验证通过，才称为同一有限树、相同规则与现金流界内的最优。

不可称为连续GBM严格最优。理论支付表、前沿值与优化目录答案只保存在评价工件，不进入模型生成反馈；已知族的公开定义可以进入提示。

预检必须同时通过基准P和P=Q：理论未证明最优／资源或时间耗尽，目录没有同目标可行比较对象，目录已经达到理论界，或目录低于证明界造成模型不一致，均阻止付费实验。预算内目录还有缺口只构成必要条件，不自动授权花费。

## 经济行为与复杂度审核

现金流在同一树的全部历史节点比较，保留金额及日期，条件Q价值和一步复制delta另报。它能识别同终值异历史支付，不用AST形状判定新颖性。

参考拟合最大腿数初始2、绝对容差0.01元加相对1e−6，固定拟合预算256；先寻找有效数值匹配证据，未通过时按相同最大绝对误差范数做minimaxLP。限额耗尽或求解失败返回inconclusive，不能增加“未匹配创新”计数。固定目录模板及非负组合匹配不覆盖全连续参数目录或任意看涨看跌张成。

程序节点数只用于复杂度分层，未匹配率必须按该分层报告。有限树匹配不是全路径经济等价证明；专家待审状态保持缺失。

## 配对统计与效力

同模型、同需求、同预算重复；每次重新建档案，反馈组可读取开发约束／现金流结果和父代，独立组无历史／父代。兄弟候选生成之前冻结一轮反馈。生成完成后冻结全部可行候选，再做理论距离、P=Q和目录匹配审核，审核不回流。

每个重复是否至少有一份候选实现主要事件，是统计单位；候选数和4096条市场路径不作重复数。精确双侧McNemar报告配对四格计数、事件率差、近似配对bootstrap区间、缺失与方向。负方向显著不称反馈改善。多主要模型采用Holm；正式建议只一个模型和一个主要需求。

先独立预实验估计p00/p01/p10/p11，再计算固定N。仅有两边事件率无法唯一确定效力；不统一宣称40或60对足够。预实验不混入正式结果；正式入口要求固定N、预注册字段、独立预实验文件与明确联合概率效力方案。禁止追加运行到显著。分析模块本身不替研究者认证预注册或允许科学显著性声明。

统计依据：[SciPy binomtest](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)、[statsmodels McNemar](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html)。求解界依据[科学计算库MILP文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)。

# 市场共同股票流动性双赛道预实验

协议 `equity-liquidity-mechanism-discovery.v1`。用户2026-10-13确认双赛道、共同流动性、DeepSeek默认推理8次总调用。入口 `experiments/run_stochopia_liquidity.py`，默认离线；`--api`加载现有私有env并调用官方API。使用现有API传输，无重试，max_tokens=393216，实际usage和原始响应逐请求保存。

## 已确认的经济口径

买方与卖方各自100万元，禁止追加；正常留出损失ES95≤资本10%，所有已列压力情景样本的最大损失≤20%。报价为独立参考样本贴现平均支付+0.1×相对平均支付的剩余卖方损失ES95；对冲工具集合是无对冲、篮子静态仓位、篮子+put静态仓位，允许候选补充可执行对冲。以参考样本内最低可行报价选取，留出冻结。收费0与0.2在同一独立报价样本上重选可行对冲，再离线复核留出；不是重新观察留出定价。卖方资金检查覆盖每个支付日与对冲占用。

这个均值加风险收费是用户批准的科研报价规则，不是唯一无套利价格或实盘报价。参考股价漂移与利率均为0，流动性与价格独立随机源；另将价格方向、波动率、价差、深度、恢复分别干预。报价和策略的期权行情是篮子ATM欧式BS近似，不能将其作为完整一致的随机波动率期权市场。

## 实际实现的环境和搜索域

10只合成股票及其等权篮子，20交易日、每交易日78个5分钟格。价差为full relative spread；每股票深度为每步可成交名义/固定市场资本；恢复为临时冲击每步衰减比例（越大越好）。根状态严格相同，共同随机数配对。市场正常深度起始为每股0.025个市场资本，非真实ADV。费用科研常数：佣金1bp、借券年率3%、冲击系数2bp、期权full spread至少20bp、短股额外保证金50%、短期权保证金100%标的名义、总敞口上限2倍资本。

A赛道是目标权重策略，证券为s0..s9/basket/call/put；权重按初始账户资本，不按变化中的财富放大。表达式消费既有DSL当前/历史操作，交易接口在Stochopia研究模块内；未来表达式拒绝。只市价、容量内部分成交；未完成股票清算标记失败，不免费按公允价退出；期权到期按法律支付结算。

B赛道复用既有DSL premium合约，external读取公开报价/深度/恢复序列；支持中途与负支付，t0额外经营支付拒绝；禁止额外funded融资包装。语言与StructurerDSL源码不变。新合约可提供hedge_policy，解释为可执行卖方策略，不接受口头对冲证明。

## 独立评价

固定参照订单分别为资本1%/10%/50%，期限5/30/120分钟；冻结每个后续公开状态，用对称买卖参照测成本、未服务比例、恢复半衰期。参照与候选交易无关，full LOB/排队未模拟。价差类别采用小单成本增加25%；深度类别采用大单立即未服务比例增加25个百分点；恢复类别采用半衰期增加25%；共同类别要求三者均成立。

只在参照标记的配对上计算净损益差；看空方向恶化−改善，看多反向。阈值资本0.1%；四类别最小覆盖率≥80%，价格/波动率非目标变化相对最小目标均值≤25%，观点分布净收益超过阈值。看空观点分布为共同恶化50%、正常40%、改善10%；看多反向。正常分布ES与所有压力情景资金/最大损失另作门槛。亏损路径不能靠外部资金补齐。

初始64开发、128独立报价、256留出路径（seed20261013/771013/881013）；尾部是有限样本诊断，不是严格总体保证。

## 搜索与对照

每赛道一对反馈/独立臂，每臂2轮1提案，合计8 API调用。每提案8个同规则规模/参数扰动，合计每臂16开发评价；每赛道目录8族×2参数评价。同样的局部扰动函数用于目录与模型。此16评价预算仅覆盖稀疏参数试验，不能称族内充分优化。生成失败消耗API次数但不自动补调用；未用开发评价预算单独报告。

A目录为现金、篮子多/空、保护put、跨式、反转、趋势、流动性阈值。B目录为流动性交换、call/put、Asian、深度数字、恢复call、occupation和B–J（half spread转换和比例系数单独处理）。这些是本轮有限控制，不是完整市场目录。B–J无生成模板地位。公开辅助liquidity指数的简单交换进入目录，防止直接支付指标被冒称创新。

两臂都使用完整任务条件，只有反馈臂读取自己的开发结果与提案。开发确定每提案代表，再冻结全部代表进行留出。不同赛道分别分析。主要输出coverage/nuisance/cost和资金/风险门槛，不以原始收益选机制赢家。

匹配仅做抽样净损益上的仿射单控制拟合，无论结果如何，新颖性均为unresolved；不替代完整现金流/策略等价、8腿组合检查、消融或专家盲审。目录比较采用受约束整体观察前沿，仅为diagnostic。理论headroom未证明，统计单位每赛道只有一对；本轮不支持显著性或确认新机制。

## 首轮提示诊断与修正

本轮8次调用使用原始提示，实际请求及原源码快照保留。发现公共辅助`liquidity`指数方向未明确，市场纯流动性干预保持股价不变的关系未明确，日程表说明容易被误读成`(obs daily)`，且`ret`的三参数签名、notional单位和原生深度限制缺少说明。模型多次采用相反指数方向、价格共变假设或非法DSL。提示已改为`2026-10-13-r2`：明确上述事实，给出无命名日程表的合法meta、收益比率签名和单次名义缩放。更新后的提示只做离线检查，没有追加API调用。首轮是接口/任务说明诊断，不能用于归因模型创新高低或反馈机制的因果效果。

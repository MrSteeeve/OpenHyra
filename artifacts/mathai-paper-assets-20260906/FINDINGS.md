# 本轮图表与补充实验结果

图表和数据已经整理完成。当前证据能够支撑“统一 Python 停时算法表征、以对偶 gap 审计的搜索环境及反馈对照实验”，但不能据此声称 Context 架构优于分数反馈，或发现了优于强基线的新停时算法。

## 本次完成的数据

- 补全七类参考算法在原始隐藏面板上的 21 次评价。
- 对原始冻结程序完成 40 次校准 gap 评价。
- 新反馈实验共 12 个预设尝试，10 个程序生成成功并完成校准，2 次 Context 超时保留。
- 选择冻结后，37 个程序完成新测试面板评价，每个 seed 四个合约实例。
- 正式补充评价合计 108 次，另做两次数值重放；所有数值评价成功，两次重放的分数和上下界数值完全一致。
- 汇总包含 116 条评价/尝试记录（含 6 条旧审计与 2 条未成功生成记录）、302 个数值实例记录。13 种方法/选择规则各有三个 seed 的主表结果。

## 最终测试中的主要数值

以下为三个 seed 的平均 gap score，越低越好。score 包含蒙特卡洛不确定性和尾部分位数项，完整 L、U、原始 gap 与 SD 见主表。

| 方法或选择规则 | 平均 gap score |
|---|---:|
| Ridge | 0.185268 |
| PCA + Ridge | 0.185036 |
| MLP | 0.195599 |
| 原始 Context 搜索，允许保留初始参考 | 0.185904 |
| 原始直接生成，允许保留初始参考 | 0.186041 |
| 新结构化反馈，按校准选择 | 0.185268 |
| 新分数反馈，按校准选择 | 0.185653 |

结构化反馈组在三个 seed 上都选择保留 Ridge，因此与 Ridge 相同的分数来自保留基线。分数反馈组在 seed 17 选择了一个校准分数稍好的新程序，但其测试分数从 Ridge 的 0.074647 增大至 0.075803；另外两个 seed 也保留 Ridge。这不是结构化反馈发现了更好算法的证据。

有一个未被校准规则选中的结构化候选在 seed 17 测试上略优于 Ridge；它保留在全部候选表中，没有据此重选赢家。不能用看过测试后的选择替换预先冻结的主结果。

PCA + Ridge 与 policy_iteration 在本组预算和测试中给出相同数值。这是当前输出的重合，不意味着两个算法在一般情况下等价。均值差异也不是统计显著性证据；独立搜索 seed 只有三个。

## 对论文叙述的影响

gap 应当是结果表和最终审计的核心指标。原始搜索实际使用的是收益改善 LCB，过程图同时给出其事后 gap 重评；不能把旧实验写成已经直接用 gap 反馈搜索。新增对照确实使用校准 gap 作为反馈和选择指标，但每个操作符只生成一个提案，没有形成新增多轮递归下降曲线。

目前最清楚的发现是：较强的 Ridge 基线很难在当前训练和搜索预算下被稳定改进；公开收益代理分数的改善不必然转化为测试 gap 的改善；保留起始策略、报告失败并冻结选择，会改变对“搜索有效”的判断。

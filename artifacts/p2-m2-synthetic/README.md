# P2-M2 synthetic intervention evidence (2026-11-27)

This directory is the new M2-only evidence bundle. No historical P1/M1 file was edited. The public synthetic intervention study uses no private market data and no external API. The exact execution revision of Stochopia is [`ef9389f3e1c20b675d1af38eb1ddb28c303d6a1d`](https://github.com/MrSteeeve/Stochopia/commit/ef9389f3e1c20b675d1af38eb1ddb28c303d6a1d). All seven numerical files are hashed in `SHA256SUMS`.

| File | Contents |
| --- | --- |
| `registration.json` | Frozen 78-fit roster, recipes, seeds, capacity, physical schedule, hypothesis decisions and pre-fit generation calibration |
| `manipulation_check.json` | Train-only Z, Tier 0 check, synthetic data/known-generator truth hashes and support |
| `experiment_results.csv` | All 78 fits, aggregate likelihood, memory and rollout metrics |
| `daily_results.json` | All 12 evaluation days per fit, including unavailable measurements as null |
| `paired_effects.json` | Candidate–parent within-world contrasts and high–low interactions, paired-day bootstrap |
| `frozen_synthetic_laws.json` | All H1–H3 decisions, including inconclusive results and Poisson equivalence |
| `execution_summary.json` | Fit counts, wall-clock and cumulative training/evaluation times, 0 API calls |

To verify data file integrity: `shasum -a 256 -c SHA256SUMS` (from this directory). The original evidence must remain immutable; reproduce into a separate fresh directory using the [Stochopia study report](https://github.com/MrSteeeve/Stochopia/blob/main/docs/research/P2-M2-Synthetic-TauZ-Study.md). The report documents the frozen registration, five tables, scope and exact command. Synthetic dataset caches and reconstructed training weights are not included; they are generated by that command.

# OpenHyra: auditing LLM program search for Bermudan stopping

Code and frozen evidence for

> Yuhua Qian. *Auditing LLM Program Search for Bermudan Stopping with Primal–Dual Certificates.*
> The 6th Workshop on Mathematical Reasoning and AI (MATH-AI), NeurIPS 2026. Poster.

OpenHyra is an open planner → proposer program-search harness. In the paper it searches over Python exercise policies for Bermudan options. A trusted evaluator owns the simulation, the exercise loop and a dual upper bound. Every candidate is re-evaluated on an independent holdout after selection is frozen.

## Repository layout

| Path | Contents |
|---|---|
| `*.py` (root) | Harness: planner (`context_agent.py`), proposer (`proposal_agent.py`), search memory (`eb.py`), sandbox, provenance, LLM backend |

| `paper/mathai2026/` | Camera-ready LaTeX source, `main.pdf`, tables, figures, and `analysis/` scripts for the reference-value calibration |

## Reproduce

Requires Python 3.10+ and `numpy`; `pytest` for the tests.

```bash
pip install "numpy>=1.26" "pytest>=8.0"
python -m pytest tests/ -q
```

Verify the frozen package (SHA-256 manifest, source hashes, numerical replay of every reported score and bound; no model calls):

```bash
python artifacts/mathai-paper-assets-20260906/scripts/verify_assets.py
```

Recompute the binomial reference values, the certificate decomposition, and the camera-ready confidence bounds (Appendix F of the paper):

```bash
python paper/mathai2026/analysis/certificate_tightness.py
python paper/mathai2026/analysis/camera_ready_stats.py
```

Build the paper with `tectonic paper/mathai2026/main.tex`.

## The frozen evidence package

`artifacts/mathai-paper-assets-20260906/` is kept byte-identical to the state recorded in its `manifest.json`, so it is not edited for presentation. It contains:

- `protocol.json`: the pre-registered protocol; `selections_frozen.json`: the selection freeze written before any holdout evaluation;
- `programs/`: every evaluated candidate and reference program; `ablation/`, `ablation_recovered/`: per-attempt records, including failed attempts;
- `raw/`: raw calibration and holdout evaluation records; `inputs/`: frozen inputs from the original search;
- `recovery_amendment.json`: the documented recovery after an infrastructure error in the first ablation run;
- `frozen_runtime/`: a snapshot of the harness code that produced the results (the root code is the current version);
- `scripts/`: the original drivers (`run_supplement.py`, `recover_supplement.py`), kept as an execution record, plus `replay_evaluation.py`, `build_assets.py` and `verify_assets.py`;
- `data/`, `tables/`, `figures/`: derived tables and figures; `FINDINGS.md`, `METHODS.md`.

Notes for readers of the package:

- Its README and findings are in Chinese, and image links in its README use absolute paths from the machine that built it; the figures themselves are in `figures/`.
- It uses the original component names: Context agent = planner, Proposal agent = proposer, Experience Bank = search memory.
- PCA + Ridge and Policy iteration are listed separately but fit the same regression and give identical numbers (paper, Appendix A).

## Disclosures

- **Models.** All candidate programs were generated by `gpt-5.6-sol` through the OpenAI Codex CLI (v0.146.0). Prompts, responses and CLI logs for each call are kept in the package, including session identifiers and absolute local paths.
- **Failures and recovery.** Failed attempts stay in every denominator: 2/12 and 3/12 proposer timeouts in the two original pipelines, and 2 planner timeouts in the structured-memory arm of the ablation. One infrastructure error in the first ablation run occurred before any proposer call; the recovery is documented in `recovery_amendment.json`, and no model call was regenerated or retried.
- **Selection.** Selection was frozen before the independent holdout; holdout results were never fed back to search. The feedback ablation selects on a calibration score.
- **Statistics.** Reported gaps are Monte Carlo estimates of the certificate width with approximate, asymptotic confidence statements only; see Section 2 of the paper.
- **Sandbox.** The macOS Seatbelt sandbox confines writes by candidate programs; it is not a confidentiality or full-isolation boundary.
- **Development tools.** The harness and analysis code were written with AI coding assistants (Claude Code and Codex). `frozen_runtime/CLAUDE.md` is the development-workflow file in use at the time of the experiments.
- **Scope.** This repository contains only the code and evidence for the paper above. Earlier pilot runs and unrelated work in progress are not included.
